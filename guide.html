まずは「テスト通知」を押してください。

この拡張は ChatGPT 本体とは別に、Chrome の拡張機能用の通知 API を使います。ただし Windows の通知ブロックを回避するものではありません。テストで通知経路を先に確認できます。

01　インストール

  1. ZIP を右クリックし、「すべて展開」で解凍します。保存先は後で削除・移動しない場所を選んでください。
  2. Chrome のアドレスバーに chrome://extensions/ と入力します。
  3. 右上の「デベロッパー モード」を ON にします。
  4. 「パッケージ化されていない拡張機能を読み込む」を押し、manifest.json が直接入っている chatgpt-completion-notifier フォルダーを選びます。ZIP 自体ではなくフォルダーを選びます。
  5. Chrome のパズル形の拡張機能メニューで「ChatGPT 完了通知（ローカル）」をピン留めします。
  6. すでに開いている ChatGPT のタブを F5 で再読み込みします。拡張を更新・再読み込みした後も同じ操作が必要です。

Python、Node.js、API キー、別の常駐アプリは、通常の利用には不要です。Chrome 116 以降向けです。組織の管理ポリシーでデベロッパーモードや拡張の追加が禁止されている場合は、管理者へ相談してください。

02　最初の動作確認

ChatGPT のタブで拡張アイコンを開き、「接続済み・待機中」を確認します。「テスト通知」を押して Windows の通知が表示されるか確認してください。「音だけテスト」ではチャイムの再生だけを試せます。

次に ChatGPT に少し長めの回答を依頼し、別のタブや別アプリへ切り替えます。回答が終わり、画面の更新が落ち着いてから標準で約5秒後に通知を送ります。バックグラウンドの制限により遅れる場合があります。

通知をクリックすると、元のタブへ戻ります。元のタブが別の会話へ移動していた場合は、通知時の会話 URL を新しいタブで開きます。ログインが必要な場合や一時チャットでは、閉じた会話を復元できないことがあります。

標準設定

通知 ON ／ ChatGPT を見ていても通知 ON ／ チャイム ON ／ 音量50% ／ 完了判定の待機5秒。「ChatGPT を見ているときも通知」を OFF にすると、対象タブを表示している前面ウィンドウでは、通知とチャイムを抑制します。

チャイムは OS の通知音とは別の音声再生です。Windows の「応答不可」中も鳴る場合があります。不要な場合は「完了時にチャイムを鳴らす」を OFF にしてください。テスト通知は、監視を OFF にしていても手動操作として実行できます。

03　通知が出ないとき

テスト通知も表示されない

Windows の設定 → システム → 通知 → Google Chromeで、通知と通知バナーを許可してください。「応答不可」や通知の自動抑制も確認します。OS によって項目名が多少異なります。

拡張画面の「通知 API への送信：成功」は、Chrome が要求を受け付けたことを示します。Windows が実際にバナーを表示した証明ではありません。この拡張から OS の抑制状態を完全に調べることはできません。

テスト通知は出るが、回答の通知が出ない

まず ChatGPT のタブを再読み込みし、拡張の状態を確認します。生成中に拡張を開き、「回答を生成中」になっているか見てください。最後まで待機中のままなら、ChatGPT の画面構造と検出条件が合っていない可能性があります。

Chrome の設定 → パフォーマンス → 常にアクティブにするサイトに chatgpt.com を追加してください。設定ページは chrome://settings/performance です。これはメモリセーバー対策であり、OS のスリープやすべてのタイマー制限を解除するものではありません。

問題が続く場合は、拡張の「診断情報（会話本文なし）」を開きます。生成中・生成後それぞれの状態と、最後の通知ログが切り分けに役立ちます。この欄はマウスで選択し、コピーできます。

通知は出るが、音が聞こえない

「音だけテスト」を押し、音量が0%でないこと、Windows の音量ミキサーで Chrome がミュートされていないこと、出力先のスピーカーやヘッドホンが正しいことを確認してください。再生失敗は診断情報に記録します。

通知が早すぎる・重複する

早すぎる場合は「完了判定の待機」を8秒または12秒に変更してください。ChatGPT 本体の通知や別の拡張が併用されていると、別々に通知される場合があります。本拡張の内部では同じ検知イベントを重複送信しないようにしていますが、複数のタブで同じ会話を監視した場合はタブごとに通知することがあります。

04　できることと限界

対象は Chrome 内で開いている ChatGPT の画面です。Windows アプリ版は監視しません。会話のタブを開いたまま別タブや別アプリで作業できますが、そのタブ内で別の会話へ移動すると元の会話の監視は終了します。複数会話を監視する場合は別タブにしてください。

停止ボタン、生成中の表示、最新の回答の変化、回答後の操作ボタンなどから終了を推定します。公式のサーバー側完了イベントではありません。通信を傍受したり、非公開 API を呼び出したり、回答を自動送信したりしません。

通常のテキスト回答が主な対象です。長い思考中でも、生成中の表示が残っている間は完了扱いにしません。ただし表示切り替え、通信エラー、ChatGPT の UI 変更などによる誤検出・未検出はあり得ます。画像生成、Deep Research、エージェント、音声の専用完了検出は未検証です。

手動の停止操作を検出した場合は完了通知を出しません。既存の完成済み会話を開いただけでは原則として通知しません。Chrome 終了、タブ閉鎖、タブ破棄・凍結、PC スリープ中の監視はできません。復帰後の過去の完了通知も保証しません。

05　権限とプライバシー

権限・処理用途
notificationsChrome からデスクトップ通知を作成するため。
storage設定の保存、通知の重複防止、セッション内の診断ログとクリック先の保存。
offscreen拡張に同梱した短いチャイムを背面で再生するため。
ChatGPT の2つのホストhttps://chatgpt.com/* と https://chat.openai.com/* の画面を監視し、そのタブを扱うため。他のサイト全体のアクセス権は要求しません。

会話本文は最新の回答の変化を調べるためページ内メモリで参照しますが、通知やログには入れず、外部へ送信・永続保存しません。通知に会話タイトルも表示しません。外部通信、広告、アクセス解析、外部スクリプト、Cookie 読み取り、API キー入力はありません。

設定は chrome.storage.local、通知の時刻・処理結果・クリック先 URL・タブ ID は chrome.storage.session に保存します。会話 URL はクエリとフラグメントを除き、ブラウザセッション内だけで扱います。通知ターゲットは最大100件、重複防止 ID は最大200件、本文を含まないログは最大20件です。シークレットウィンドウは対象外です。

検証した範囲

状態判定・通知処理の自動テスト37項目と、Chromium のオフライン模擬画面による DOM / 操作テスト8項目が成功しています。ブラウザの模擬テストでは Chrome 拡張 API をモックに置き換えています。

実際の拡張読み込み、Windows の通知バナー・実際の音声出力、ログイン済み ChatGPT の最新画面は未確認です。検証環境の管理者ポリシーで拡張の読み込みが禁止されているため、実機での最初のテストを必ず行ってください。詳細は tests/TEST_REPORT.md に記載しています。

更新・削除・ソースコード

更新時はフォルダーのファイルを差し替え、chrome://extensions/ のこの拡張の再読み込みボタンを押します。その後 ChatGPT の各タブも再読み込みしてください。

削除は拡張機能画面の「削除」から行います。アンインストール後に保存フォルダーを削除できます。ソースコードはすべて同梱しています。MIT License の条件で変更・利用できます。Chrome ウェブストアでの公開や自動更新は行っていません。
