## 検証方法の重要な制限

**Chrome 拡張 API はモックです。**
DOM テストはブラウザの通常ページ上にローカル HTML と本体の content.js を読み込み、
実際の DOM、MutationObserver、信頼されたクリックを利用します。
拡張の isolated world、manifest による自動注入、Chrome のネイティブ通知・音声 API の
成功を証明するものではありません。URL 遷移ロジックは Node の合成スナップショットで
別途テストしています。実サイトへの通信は行っていません。

**実際の拡張読み込み、Windows の通知バナー・スピーカー出力、ログイン済みの
ChatGPT の最新 DOM は未検証です。**
検証環境では管理者ポリシーにより拡張の読み込み・URLナビゲーションが禁止されている
ため、ポリシーを変更せず、オフラインの通常ページ上でのテストを実施しました。
バックグラウンドの凍結や OS スリープも未検証です。

## 利用PCでの受入確認

1. インストール後に ChatGPT のタブを再読み込みし、拡張を開いて接続状態を確認。
2. 「テスト通知」で Windows のバナーを確認。
3. 「音だけテスト」で実際の音を確認。
4. 通常の回答を別タブで待ち、終了後の通知を確認。
5. 通知クリックが元の会話を開くことを確認。
6. 生成中に停止操作を行い、完了通知が出ないことを確認。

ログ `sent` は Chrome が要求を受け付けたことを示すだけで、OS の実表示を保証しません。

## 再実行（開発者向け）

```sh
node --test tests/detector.test.cjs tests/background.test.cjs
python tests/browser_dom.py --chromium /path/to/chromium --report browser-results.json
```

Node テストは外部依存パッケージ不要です。DOM テストは Python の Playwright と Chromium
が必要です。拡張を普通に利用するだけなら、これらのインストールは不要です。
