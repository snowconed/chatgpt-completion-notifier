旧版 v1.0.0 を別の一時フォルダーに取り出し、新しい回帰テストを実行しました。
従来のテキスト回答ケースは成功し、空の本文の兄弟に iframe がある回答で
`hasOutput` が false のままになることを再現しました。修正版ではそのケースで
出力を検出し、待機時間の経過後に一度だけ完了イベントを発行します。

追加した DOM ケースは、SVG・canvas・埋め込み画面、通常形式と data-turn 形式の
混在、生成中・手動停止時の抑制、遅れて追加される終了操作、SVGの形状変更、
過去回答とユーザー添付の除外、非表示要素や小さい装飾の除外、拡大ボタン内の画像、
canvasの代替文と図専用Copyボタンによる早すぎる判定の防止を確認します。

図だけの回答は、親チャットの生成中表示が消え、回答後の操作と入力欄の両方が
利用できる状態になってから安定確認の待機時間を計測します。
画像・図のマークアップはページ内での一時的なハッシュ計算だけに使い、診断には
種類・個数・真偽値のみを追加しています。本文・図・URL・ハッシュは送信しません。
通知クリック先の会話URLをセッション内で扱う従来の処理は変えていません。

**この検証もChrome拡張APIはモックです。今回の実際のChatGPT画面構造と、
Windows通知の表示は未検証です。** iframe内部やcanvas描画の完了を直接観測する
ものではなく、親チャットの終了表示に依存します。48px未満の小さい図、本文や
回答turnの外に置かれた図、独自の終了表示は引き続き見落とす場合があります。

実施日: 2026-09-08

## 成功した検証

- Node.js v22.16.0: 状態機械・設定/URL検証 22項目、サービスワーカー処理 15項目。合計 **37 / 37 成功**。

- 配布 JavaScript の `node --check` による構文検査。
- 設定画面のスクリーンショットによるレイアウト確認（模擬API）。

### DOM テストの内容

既存の会話を開いたときの抑制、生成中の長い本文停止、完了後の単発イベント、
手動停止、非常に速い回答、日本語の停止ラベル、終了直前の追加出力、複数タブの
独立監視、設定画面とテストボタンの配線を8つのケースにまとめて検証しています。

### ワーカー等のテストの内容

通知要求、イベント重複防止、複数タブからの同時要求、前面時の抑制、最小化、
監視OFFでも手動テスト可能、通知権限拒否、音声失敗と通知処理の分離、
不正送信元とサブフレームの拒否、通知クリック、ワーカー再作成後のターゲット維持、
別会話を上書きしないタブ移動、閉じたタブの再作成、安全なURL処理などです。

## 検証方法の重要な制限

**Chrome 拡張 API はモックです。**
DOM テストはブラウザの通常ページ上にローカル HTML と本体の content.js を読み込み、
実際の DOM、MutationObserver、信頼されたクリックを利用します。
拡張の isolated world、manifest による自動注入、Chrome のネイティブ通知・音声 API の
成功を証明するものではありません。URL 遷移ロジックは Node の合成スナップショットで
別途テストしています。実サイトへの通信は行っていません。

**実際の拡張読み込み、Windows の通知バナー・スピーカー出力、ログイン済みの
ChatGPT の最新 DOM は未検証です。**
検証環境では管理者ポリシーにより拡張の読み込み・URLナビゲーションが禁止されている
ため、ポリシーを変更せず、オフラインの通常ページ上でのテストを実施しました。
バックグラウンドの凍結や OS スリープも未検証です。

## 利用PCでの受入確認

1. インストール後に ChatGPT のタブを再読み込みし、拡張を開いて接続状態を確認。
2. 「テスト通知」で Windows のバナーを確認。
3. 「音だけテスト」で実際の音を確認。
4. 通常の回答を別タブで待ち、終了後の通知を確認。
5. 通知クリックが元の会話を開くことを確認。
6. 生成中に停止操作を行い、完了通知が出ないことを確認。

ログ `sent` は Chrome が要求を受け付けたことを示すだけで、OS の実表示を保証しません。

## 再実行（開発者向け）

```sh
node --test tests/detector.test.cjs tests/background.test.cjs
python tests/browser_dom.py --chromium /path/to/chromium --report browser-results.json
```

Node テストは外部依存パッケージ不要です。DOM テストは Python の Playwright と Chromium
が必要です。拡張を普通に利用するだけなら、これらのインストールは不要です。
