ChatGPT 完了通知（ローカル） v1.0.0
作成日: 2026-09-08

最初に guide.html を開くと、詳しい日本語ガイドを読めます。

【導入】
1. ZIP を「すべて展開」で解凍する。
2. Chrome のアドレスバーで chrome://extensions/ を開く。
3. 「デベロッパー モード」を ON にする。
4. 「パッケージ化されていない拡張機能を読み込む」を押す。
5. manifest.json が直接入っている chatgpt-completion-notifier フォルダーを選ぶ。
6. 拡張をピン留めし、開いている ChatGPT のタブを F5 で再読み込みする。
7. 拡張アイコンから「テスト通知」を押す。

通常の利用に Python / Node.js / API キーは不要です。
Chrome 116 以降向け。Windows アプリ版は監視しません。
Chrome ウェブストア未公開の、非公式・ローカル導入用の拡張です。
拡張を使う間は、このフォルダーを削除・移動しないでください。
管理ポリシーで導入できない場合は、管理者に相談してください。

【使い方】
ChatGPT の会話をタブで開いたまま質問を送信します。
別タブや別アプリで作業しても監視します。
画面上で生成終了を検出し、標準で約5秒の安定確認後に通知します。
通知クリックで元の会話を開きます。
チャイムは標準で ON、音量50%。個別に OFF にできます。
「ChatGPT を見ているときも通知」は標準で ON です。

【通知が出ない場合】
テスト通知も出ない:
  Windows の設定 → システム → 通知 → Google Chrome、通知バナー、
  応答不可を確認してください。拡張から OS の通知制限は回避できません。
  「送信成功」は Chrome の受付であり、Windows での表示の証明ではありません。

テスト通知は出るが回答の通知が出ない:
  ChatGPT タブを再読み込みし、生成中に拡張が「回答を生成中」となるか確認。
  Chrome の設定 → パフォーマンス → 常にアクティブにするサイト に
  chatgpt.com を追加してください。設定ページ: chrome://settings/performance
  それでも検出しない場合は、拡張の「診断情報（会話本文なし）」を確認。

チャイムは Windows の通知音とは別に再生されるため、応答不可中も鳴る
場合があります。不要な場合は拡張のチャイム設定を OFF にしてください。

【限界】
・公式の完了イベントではなく、画面を監視する推定処理です。
・主な対象は通常のテキスト回答。特殊モードや UI 変更では誤検出・未検出があり得ます。
・PC スリープ、Chrome 終了、タブ閉鎖・破棄・凍結中は監視できません。
・同じタブで別の会話へ移ると、元の会話の監視は終了します。
・同じ会話を複数タブで監視した場合は、タブごとに通知する場合があります。
・画像生成 / Deep Research / エージェント / 音声の専用検出は未検証です。

【プライバシー】
会話本文の変化はページ内メモリで参照するだけです。
会話本文・会話タイトルを通知に表示せず、保存も外部送信もしません。
外部 API、外部スクリプト、広告、アクセス解析はありません。
設定は chrome.storage.local、本文なしの通知ログ・重複防止情報・
クリック先 URL とタブ ID は chrome.storage.session に保存します。
会話 URL はクエリとフラグメントを除き、ブラウザセッション内だけで扱います。
要求する権限は notifications / storage / offscreen と ChatGPT の2ホストです。
シークレットウィンドウでは動作しません。

【検証】
Node.js の自動テスト37項目と、Chromium のオフライン模擬 DOM テスト8項目が成功。
Chrome 拡張 API はテストではモックを使用。
拡張の実インストール、Windows の通知表示・実音声出力、ログイン済み ChatGPT
での動作は未検証です。検証環境は管理者ポリシーで拡張導入が禁止されています。
初回は必ずご自身の PC でテスト通知と実際の回答を確認してください。
詳細: tests/TEST_REPORT.md

【構成】
manifest.json       Chrome 拡張の定義・権限
content.js          ChatGPT の DOM 監視と操作検知
 detector-core.js   判定用の状態機械
shared.js           設定の検証・安全な URL 処理
background.js       通知・重複防止・クリック時のタブ移動
popup.html/css/js   設定・通知テスト・診断画面
 offscreen.html/js  チャイム再生
assets/             アイコン、同梱チャイム
 guide.html/css     日本語ガイド
 tests/             開発者向けテスト（利用時の実行は不要）

【開発者向け・任意】
依存パッケージなしのテスト: node --test tests/detector.test.cjs tests/background.test.cjs
DOM テスト: Python / playwright / Chromium が必要。詳細は tests/browser_dom.py を参照。
ChatGPT の UI が変わった場合は、まず content.js のセレクターを確認してください。
UI のテキスト変化だけで完了を決めないことが、思考中の誤通知防止に重要です。
